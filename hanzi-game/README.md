# 字芽岛 · 小学识字小游戏

独立静态网页，入口 `/hanzi-game/`。在仓库根目录运行 `npm start`，使用该服务的 `/hanzi-game/` 路径。需要通过 HTTP 加载 ES 模块和 JSON；无第三方运行依赖、账号或 API 密钥，无需构建。根站页脚已加入入口。

## 内容与适用范围

面向南京小学生，使用统编版**旧版**小学语文十二册实际识字表、写字表。来源是第三方公开镜像，不是南京教育主管部门发布的字表，尚未确认南京各校当前教材和 2024 年起修订教材的适用性。请按学校实际教材核对；不声称完成当前南京教学字表认证。

来源：`TapXWorld/ChinaTextbook` 固定提交 `e2b3f62213c77bb8c33c5be355f97625ea1b8b61` 的 `小学/语文/统编版/`。实际读取十二册 PDF，提取末尾识字表和写字表；未复制课文、插图或分发教材 PDF。

| --- | ---: | --- | --- |
| 一 | 700 | 300／100 | 400／200 |
| 二 | 1129 | 450／250 | 450／250 |
| 三 | 842 | 250／250 | 250／250 |
| 四 | 814 | 250／250 | 250／250 |
| 五 | 651 | 200／220 | 200／180 |
| 六 | 294 | 未单列／180 | 未单列／120 |

全库共 **2999 个不同汉字**，跨年级重现的字不重复计入此总数；表格内各年级字数不能相加作为全库字数。识字表与写字表重叠，识字表蓝色多音复习字不计入教材标注的“新增生字”数量，但可供练习。六年级镜像未单列识字表，不代表只需认得这 294 个字。

`data.json` 逐册保存来源路径、完整提交、PDF SHA-256、PDF 页序及标注数量。所有字表计数经过自动校验；不等同于对所有语音和教材版本的人工审校。识字表拼音转换自 PDF 字体编码，写字表未标音的字与词语拼音使用 pypinyin 0.55.0 生成。词语优先选取对应册词语表中读音一致的条目，另补充自编常用组词，字卡注明来源。多音字卡展示当前语境读音；干扰项排除与目标任何已知读音重合的字。生成的拼音仍可能有语境误差，请结合教师讲解使用。

## 功能

- 一至六年级、上下册／全年、识字表／写字表筛选。
- 翻卡认字、词语和拼音提示；设备有普通话语音时可朗读。语音不可用会提示，绝不作为自动听力评分。
- 拼音找汉字、汉字找拼音，每轮最多十题；按二十字分片，也可直接开始。
- 答错进入“再见一面”，以后独立答对移出；连续三轮答对显示小树苗。每题只提交一次，重复点击不计分；翻卡、描写不计答题成绩。
- 答错即时优先，答对按连续次数在 1、3、7 天后优先复习。不是经科学评估的掌握度诊断。
- 田字格支持触屏、鼠标、触控笔自由描写与擦除；不含笔顺识别或书写评分。
- 本地存储、导出／导入 JSON。无登录、无跨设备自动同步。导入按最后作答时间合并，数据损坏时不静默覆盖原记录。
- 清空记录前明确二次确认。声音由系统语音服务提供，部分系统语音需要联网；页面初次加载需要网络，未实现离线缓存。

## 维护与验证

```sh
node --test hanzi-game/model.test.js
# 全仓回归测试
npm test
# 浏览器冒烟验证（开发环境另需 Python playwright 和 Chromium）
python3 hanzi-game/scripts/browser-smoke.py
```

浏览器验证使用已运行的根目录 HTTP 服务 8000 端口，检查手机／平板布局、六年级空识字表、完整闯关、错误复习、进度持久化、描写、备份恢复及异常提示。只在本机测试，不向外部平台发布。

重新生成字表：将对应镜像文件放在临时目录，命名为 `g1-upper.pdf`、`g1-lower.pdf` …… `g6-lower.pdf`，安装生成工具 PyMuPDF 和 pypinyin 0.55.0，执行：

```sh
python3 hanzi-game/scripts/extract-data.py /tmp/hanzi-textbooks
```

脚本本身不联网、不下载、不发布教材。新增或更换参考版本时应重新核对来源、PDF 页序、字表数量、拼音和词语，并更新适用说明；不要只改年级标签。
