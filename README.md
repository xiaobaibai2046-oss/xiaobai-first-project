# 向野 · 山野自驾路书

适合手机与电脑的中文旅行规划网页，无第三方运行依赖，不需要 API 密钥。

## 运行

在仓库目录运行 `npm start`（需要 Python 3；也可直接运行 `python3 -m http.server 8000 --bind 0.0.0.0`），浏览器访问服务器的 8000 端口。`index.html` 已内嵌样式、路线数据和脚本，也可直接打开或用于单文件预览。修改 `style.css`、`data.js`、`app.js` 或 `scripts/index.template.html` 后运行 `npm run build` 重新生成页面。

`npm test` 运行 Node.js 内置测试；`node --check app.js` 检查交互代码语法。

## 功能

- 川藏南线、伊犁环线、南疆人文、拉萨至改则、改则至民丰、民丰经塔中至轮台、且末至塔中，以及乌鲁木齐—哈密—罗布泊镇—米兰—若羌—且末—塔中—库尔勒—乌鲁木齐环线，北疆环线及云南三条环线，以及青海三条环线，加甘肃三条环线，共十八条路线 / 规划。改则至民丰为待核实的 G216 方向方案，天数与中途住宿仍待核实，818 公里总里程由用户提供；可在西藏、新疆两个筛选下找到，按天数筛选时不归入已知天数组。
- 按目的地、天数、城市和美食筛选。
- 现有 85 个不同名称的站点共用城市攻略，各有至少 3 项景点 / 看点、3 项住宿候选或查找方向、3 项菜品建议，附推荐理由与地图查询。
- 按每晚每间 300—600 元、舒适型和停车便利偏好查询住宿；预算是目标而非实时报价，部分具体候选可能超预算。
- 搜索也覆盖攻略中的景点及酒店名称，导出路书包含完整推荐内容。
- 高德地图外部查询酒店、餐饮和景点；手机可按地图页面提示打开地图应用。
- 每条路线配卫星地图概览：红色站点连线、方向箭头、起终点、待核实路段虚线，支持缩放、移动、恢复全程和点击站点。
- 本机浏览器收藏（localStorage），导出 UTF-8 文本路书。

新增环线保留用户指定的停靠顺序，但哈密—罗布泊镇—米兰段通行、接待和补给未核实，2668 公里总里程由用户提供，天数及实际通行仍需核实。站点编号代表停靠顺序而非每日行程；不可将罗布泊镇停靠理解为可进入湖盆、保护区或生产作业区。

## 数据边界

`data.js` 为人工整理的示例规划数据，不是实时旅游数据库。天数、里程、海拔仅供参考，实际以道路、天气与个人状态为准。南疆路线包含长距离转场，需要分段驾驶并预留机动时间。未接入实时地图、酒店库存、价格、餐厅营业状态或 GPS 定位；没有已实时核验的酒店名单。当前有 36 条具体酒店候选记录，其余站点列出住宿查找方向；查找方向可能返回同一家商家，不代表三家已确认酒店。未提供实时评分或“最佳”排名。美食以当地 / 区域菜品为主，不声称有三家已核验餐厅。罗布泊镇等站点的三项看点包含允许活动范围，不代表三个正式开放景点。通过地图链接查询商家后，请核实当前价格、房态、评价和营业时间。

西藏及新疆部分地区可能涉及通行或边境手续，出发前向当地官方渠道确认。高海拔行程需循序适应，必要时咨询专业人士。

## 文件

- `index.html`：页面结构
- `style.css`：响应式布局与无外部资源的山野插画
- `data.js`：路线、筛选与导出逻辑
- `recommendations.js`：城市攻略、推荐理由、住宿偏好及查询关键词
- `app.js`：界面交互
- `tests/routes.test.js`：核心数据逻辑测试

后续可接入有授权的地图和酒店服务、出发城市规划、每日路线计算、跨设备同步。当前版本全部静态运行，不上传个人信息。

## 单文件预览

`npm run build` 生成自包含 `index.html`，避免预览面板无法读取相对路径的 CSS / JavaScript 导致页面无样式、路线为空。平台若限制脚本执行，仍需通过常规浏览器使用；收藏保存失败会提示且不阻止页面加载。

## 地图链接打不开

点击地图或商家查询后会显示查询窗口，提供高德、百度备用入口以及可复制的完整地址。部分预览面板限制弹出窗口和剪贴板；此时手动复制地址，在系统浏览器粘贴打开，或在地图应用搜索窗口显示的关键词。无法从网页绕过平台的外部跳转限制。

## 卫星路线图

`route-map.js` 使用站点近似 WGS84 坐标与 Web Mercator 投影，加载 Esri World Imagery 公共影像瓦片。底图来自 `server.arcgisonline.com`，必须联网，页面保留影像来源署名；服务可用性、影像日期及详细贡献方以 Esri 服务为准。当前云环境的网络策略返回 403，因此真实影像加载尚未在本环境验证；瓦片请求、地图叠加、交互与失败回退通过模拟响应验证。

红线是站点间直线示意，不是道路导航、不代表可通行路线、精确里程或当天路况。改则—民丰和环线中的哈密—罗布泊镇—米兰段用虚线标示未核实通行。沿途点位采用城镇近似位置；同一城镇的起终点编号略作屏幕偏移以便点击。缩放和方向键仅用于查看地图，不会改变实际路线。离线或瓦片失败时仍可查看红色站点连线，并显示明确提示。

## 餐厅对比

美食页提供菜品对应餐厅的优势 / 劣势表格，支持地图查询、搜索和路书导出。`restaurants.js` 当前仅列成都龙抄手、钟水饺、蜀九香火锅三个品牌候选，尚未核验具体门店与当日菜单；不能理解为已实地核实的推荐。其余站点明确显示资料待核验，不用虚构商家凑数。当前网络仍限制餐饮资料检索，全站具体餐厅内容尚未补齐。优势为品牌类型与就餐场景说明，劣势字段明确区分未知条件，不宣称未经验证的排队、卫生或停车情况。

## 用户提供的总里程

改则—民丰 818 公里；且末—塔中 217 公里；乌鲁木齐—哈密—罗布泊镇—米兰—若羌—且末—塔中—库尔勒—乌鲁木齐环线 2668 公里。来源均标注为用户提供，同步显示在路线卡片、路书摘要、地图角标和导出文本中；不代表地图 API 实时测距或道路已开放。

## 返回与餐厅替代检索

路书顶部提供随滚动保持可见的“返回路线列表”，返回前一次打开卡片时的位置，保留地区、关键词、天数与收藏筛选；直接进入路书时返回探索区域。餐厅查询不再只依赖高德：可通过百度 / Bing 对大众点评、美团、携程资料作站点限定检索，或综合查询菜单、近期评价、停车。各入口是真实搜索链接，不声称读取到平台实时评分或完成全城餐厅核验；新渠道在云环境中仍受 403 网络限制，因此其他城市的餐厅数据未因此自动补齐。

## 自驾准备与风险

每条路线包含证件、车辆、饮食衣物、健康、通讯与环保清单，并按线路增加高原、沙漠和偏远补给准备。风险卡片同时列出提前防范与出现情况后的应对；不代表实时天气预警、通行许可或医疗建议。勾选进度按线路独立保存在当前浏览器，导出路书会包含完整清单及当次勾选状态；更换设备或清除浏览器数据不会自动同步。

## 路线图封面

各条路线的卡片封面由 `route-covers.js` 根据各自站点坐标生成独立 SVG 图片，内嵌在单文件页面中，不依赖外部底图。封面显示路线红线、方向、站点编号、起终点、总里程及北向标识；未核实通行段为虚线。路线为站点直线连接，不是精确公路轨迹，背景是装饰网格而非卫星图。

## 北疆环线

新增乌鲁木齐—富蕴—可可托海—布尔津—喀纳斯—禾木—布尔津—乌尔禾—克拉玛依—乌鲁木齐，参考 12 天、约 2300 公里（规划估算，非实时测距）。包含路线图封面、卫星站点示意、每站三项看点 / 住宿查找方向 / 美食建议、餐厅多渠道检索、北疆专项清单与风险、收藏和导出。新站点暂无已核实酒店和餐厅名单，不以查找方向冒充实际商家；景区交通、门票、住宿及早雪情况需出发前确认。

## 云南板块

新增独立云南筛选及三条昆明出发环线：滇西北（大理—丽江—香格里拉—沙溪—楚雄，10 天约 1800 公里）、滇南（玉溪—普洱—景洪—勐海—临沧，10 天约 1700 公里）、滇东南（石林—弥勒—普者黑—建水—元阳—抚仙湖，8 天约 1300 公里）。里程均为规划估算，非实时导航数据；支线、机动及季节会改变实际行程。景迈山、翁丁等在攻略中明确为额外支线，不默认在主线当日顺路。每站配三项看点、住宿查找方向和美食，延续路线封面、卫星示意、餐饮查询、收藏、独立物资清单、风险提示及导出功能。云南餐厅及具体酒店未实时核验，不填造假排名或报价。

## 青海板块

西宁出发三条闭合环线：青海湖小环线（湟源—青海湖—刚察—祁连—门源，6 天约 1000 公里）；青甘大环线（青海湖—茶卡—德令哈—大柴旦—敦煌—嘉峪关—张掖—祁连—门源，10 天约 3000 公里，跨青海甘肃）；青海南部人文环线（贵德—共和—玛沁—同仁，8 天约 1500 公里）。里程是规划估算，非实时测距；部分日程包含两个停靠点，并非承诺所有景点都能串完。每站三项看点、住宿查找方向、美食和多渠道餐厅查询，延续封面、地图、物资清单、风险、收藏与导出。高原适应、雨雪、盐湖开放和景区预约需自行结合当日官方信息确认。

## 甘肃板块

新增兰州出发的河西大环线（武威—张掖—嘉峪关—敦煌—大柴旦—德令哈—青海湖—西宁，12 天约 3200 公里，跨甘青）、甘南环线（临夏—夏河—合作—郎木寺—迭部—宕昌—岷县—临洮，10 天约 1800 公里）、陇东南环线（天水—徽县—成县—陇南—宕昌—岷县，8 天约 1700 公里）。均返回兰州；公里数为规划估算，非实时导航。郎木寺格尔底寺在四川侧，攻略已说明可选跨省支线。甘肃筛选另包含已有青甘大环线，共四张卡片；青海筛选也显示新的河西跨省环线。各站延续三项看点、食宿查询、路线图、物资风险和导出，不伪造实时酒店与餐厅名单。
