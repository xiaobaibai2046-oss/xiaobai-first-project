## 技术筛选与提示（最新真DIF规则）

买入先通过2025年年报ROE严格大于10%的股票池，再在最新完整60分钟K线上筛选一次／二次真DIF底背离；MA20不是买入门槛。
MACD仍为EMA12/26/9，至少100根已完成小时线。

- 前一波取最近完整MACD绿柱波段，低点取该波最低价（同价取最近一根），DIF取该价格低点对应值。
- 当前K线必须严格低于前60根最低价，并为当前绿柱波段最低价，同时低于前一波最低价。
- 本轮低点DIF必须高于前轮对应DIF、两者均在零轴下；本轮整个波段的最低DIF也必须高于前轮最低DIF。
- 本轮绿柱峰值绝对值严格小于前轮峰值，排除仅绿柱缩短但DIF创新低的情况。
- 当前新低成交量严格小于前波低点及其前两根成交量的三根均量。
- 根据已结束波段是否连续满足同一套条件计数：一次、二次允许，三次及以上只标风险、不买入；同波重复新低不增加次数，不合格波段重置连续次数。
- 只在满足条件的当前K线收盘触发，不延续8根，也不再等待底部右侧两根确认；无未来函数或回填信号。

日线MA20继续作为趋势展示及卖出依据；原顶背离卖出仍按严格分型、左右2根、间隔5—60根、右侧2根确认、确认后8根有效。
单股财务总评仍独立展示；研究资料不完整不等于技术信号不存在，ROE门槛不可省略。

## 自动财务分析及结论

东方财富RPT_LICO_FN_CPD最近8期财报，显示报告期、公告日、营收、归母利润、同比、EPS、每股经营现金流和ROE。ROE放在主要依据第一条，保留百分比和“累计口径，未年化”说明；缺失不当作零。

当前数据完整、利润为正、营收和利润同比不下降、非金融企业现金流／EPS粗略匹配≥0.8、收盘>MA20、ATR／收盘≤4%时，可列入研究观察；这与技术买入提示是不同的输出。金融企业不机械套用工业企业现金流阈值。风险警示或近期累计亏损优先提示风险；数据不足不生成有利结论。

报价和日线的新近门槛为10个自然日，财报期末为240日。它不是交易日历或公告期限核验，仍需核对实际日期。估值仅展示有效的供应商PE(TTM)，没有行业可比及未来盈利假设时不宣称便宜或贵、不生成目标价。未自动审计负债、关联交易、质押、退市和财务真实性。

## 回测的适用范围

页面回测当前为 **MA20日线基准实验，不包含60分钟MACD背离**，不能称为新联合策略的历史收益。

日线收盘>MA20生成买入信号，收盘<MA20或入场价减2×ATR生成退出信号，下一根日线开盘尝试成交。保留T+1、零量不成交、100股整手、现金上限、费用、滑点和保守开盘涨跌幅过滤。默认仅普通沪深主板，不支持ST、退市标识、创业板、科创板及北交所回测。至少22根日线；快慢双均线参数已移除。

一键分析中的历史实验使用100万元假设账户、单笔风险0.5%，与个人账户无关。高级工具可调整资金和费用。卖出印花税按2023-08-28前后0.1%／0.05%，过户费按2022-04-29前后0.002%／0.001%分段，更早历史费率未完整覆盖。

未建模现金分红、送转、配股、成交容量、历史ST／新股及完整涨跌停排队，不复权除权窗口可能失真。期末不强制平仓，收盘估值未扣未来卖出费用。基准为满仓价格变化，不计费用和分红。当前财报不用于过去信号，交易样本不足不证明策略有效。

## 买卖颜色分类与全池扫描

ROE池有独立导航：全部、**买入信号（红色）**、**卖出信号（绿色）**、暂未触发、待扫描／更新、信号数据不足。颜色同时用于股票名称与文字标记，不只依赖颜色。单只“一键分析”完成后会自动同步对应池内分类。

全池扫描复用summarizeStock／makeTradeHints。先检查最新完整60分钟K线；底背离触发买入时只需小时线，不再读取报价财报作为门槛，也不因缺少日线而拒绝买入。顶背离仍触发卖出。其他股票继续读取日线核验MA20卖出条件；没有完整数据不冒称已验证无信号。日线卖出记录在下一个小时收盘时也会重新核验，防止漏掉后来出现的底背离。

颜色另要求匹配最新应完成的日线／60分钟时段，旧信号会转为灰色待更新；一键分析中的历史数据仍带实际截至时间。新交易时段、收盘后的日线切换都会触发过期。周末回退到上一工作日；目前未接入法定休市日历，节假日可能保守显示待更新，不能据此认定有新交易。

点击“扫描／继续全池”分批检查，最多2只同时进行，每只之间限速；可暂停，已开始的最多2只会完成后保存。本机缓存逐批保存，关闭后可恢复；浏览器限制存储时会提示。连续网络失败会暂停，不对接口绕过限流。单只无覆盖不等于全站断网。数据缺失与无信号分开，空买入名单不代表尚未核验的股票均不符合条件。

发布包内嵌pool-signals.json检查快照，仅包含公开行情的结果和日期，不含个人笔记或仓位。每只股票记录规则版本、检查时间、日线和60分钟截至时间及触发依据；页面按当前时间重新核对过期状态。attempted_all仅表示每只都有一次检查记录，不能当作全部数据齐全或当前仍有效。
