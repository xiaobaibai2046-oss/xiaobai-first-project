# 知衡 · A股研究台

手机入口：https://xiaobaibai2046-oss.github.io/xiaobai-first-project/stock/

首页输入六位股票代码，点击“一键分析”或回车。软件并行获取报价、日线、60分钟K线和财报，先展示研究结论、买入提示、卖出提示、ROE及主要依据。六步明细和高级工具按需展开。笔记保存在当前浏览器，可导出 JSON；不同设备不自动同步。

## 技术筛选与提示

- 日线趋势只用 **收盘价 > MA20**，不再使用 MA60。至少20根已完成日线可计算；量比还需前20日成交量，因此少于21根时量比显示缺失。
- 买入观察：近期日线收盘 > MA20，且近期已确认60分钟MACD底背离，同时没有卖出观察冲突或尚未核查的数据／基本面风险条件。
- 卖出／减仓观察：近期日线收盘 < MA20，或近期已确认60分钟MACD顶背离。仅供已有持仓者参考，不自动下单。卖出优先于买入，未提供持仓成本时不生成个性化订单。
- 数据缺失与“没有信号”严格区分。日线缺失不冒称已检查MA20；若仅有已知的跌破MA20事实，仍可显示对应卖出观察，并注明60分钟判断未完成。

### 60分钟MACD的明确口径

MACD参数为 EMA12、EMA26、DEA9；DIF = EMA12 − EMA26，柱值 = 2×(DIF−DEA)。EMA以首个收盘价初始化，前78根不识别拐点，至少需100根已完成K线。

背离使用DIF，**不使用柱面积**：

- 价格严格分型，左右各2根。低点必须低于左右2根的最低价，高点必须高于左右2根的最高价；同价平台不识别为严格分型。
- 比较相邻同类拐点，间隔5—60根。
- 底背离：价格低点降低、DIF低点抬高，两个DIF均小于零。
- 顶背离：价格高点升高、DIF高点降低，两个DIF均大于零。
- 第二个拐点右侧2根收盘后才确认；信号确认后最近8根以内有效。页面显示两个拐点和确认时间；不把确认后的信号回填到拐点发生时。

仅接收北京时间10:30、11:30、14:00、15:00的60分钟结束时间，排除结束时间晚于当前时刻的未收盘K线。所有价格当前均不复权，除权可能影响均线和背离。

## 自动财务分析及结论

东方财富RPT_LICO_FN_CPD最近8期财报，显示报告期、公告日、营收、归母利润、同比、EPS、每股经营现金流和ROE。ROE放在主要依据第一条，保留百分比和“累计口径，未年化”说明；缺失不当作零。

当前数据完整、利润为正、营收和利润同比不下降、非金融企业现金流／EPS粗略匹配≥0.8、收盘>MA20、ATR／收盘≤4%时，可列入研究观察；这与技术买入提示是不同的输出。金融企业不机械套用工业企业现金流阈值。风险警示或近期累计亏损优先提示风险；数据不足不生成有利结论。

报价和日线的新近门槛为10个自然日，财报期末为240日。它不是交易日历或公告期限核验，仍需核对实际日期。估值仅展示有效的供应商PE(TTM)，没有行业可比及未来盈利假设时不宣称便宜或贵、不生成目标价。未自动审计负债、关联交易、质押、退市和财务真实性。

## 回测的适用范围

页面回测当前为 **MA20日线基准实验，不包含60分钟MACD背离**，不能称为新联合策略的历史收益。

日线收盘>MA20生成买入信号，收盘<MA20或入场价减2×ATR生成退出信号，下一根日线开盘尝试成交。保留T+1、零量不成交、100股整手、现金上限、费用、滑点和保守开盘涨跌幅过滤。默认仅普通沪深主板，不支持ST、退市标识、创业板、科创板及北交所回测。至少22根日线；快慢双均线参数已移除。

一键分析中的历史实验使用100万元假设账户、单笔风险0.5%，与个人账户无关。高级工具可调整资金和费用。卖出印花税按2023-08-28前后0.1%／0.05%，过户费按2022-04-29前后0.002%／0.001%分段，更早历史费率未完整覆盖。

未建模现金分红、送转、配股、成交容量、历史ST／新股及完整涨跌停排队，不复权除权窗口可能失真。期末不强制平仓，收盘估值未扣未来卖出费用。基准为满仓价格变化，不计费用和分红。当前财报不用于过去信号，交易样本不足不证明策略有效。

## 数据接口与安全

- 腾讯报价：`qt.gtimg.cn`，供应商延迟无保证，显示交易所时间。
- 腾讯日线：`web.ifzq.gtimg.cn`，最近至多640根，今日未到16:00不纳入日线策略。
- 腾讯60分钟：`ifzq.gtimg.cn/appstock/app/kline/mkline`，m60，最近至多320根。
- 财报：`datacenter-web.eastmoney.com`。

静态版不用临时Python进程，通过隔离iframe读取公开脚本；sandbox不含allow-same-origin，数据脚本不能访问父页面笔记或localStorage。固定HTTPS域名、代码验证、时间和OHLC校验；不关闭TLS验证。接口限流或失败会明确报错，不使用演示数据冒充。公开接口不保证稳定性或再分发授权，产品化需核对许可。

数据缓存：报价10秒、日线5分钟、60分钟1分钟、财报1小时，附原始抓取时间。

## 本地运行、构建与发布

Python3.9+（含时区数据库）和Node.js18+即可，无第三方运行依赖，无需npm install或API密钥。

```sh
cd stock/source
npm start
npm test
npm run test:api
npm run build -- ..
```

`npm start`运行Python后端8010端口（仅本地开发模式需要）。API：`/api/quotes?codes=600519`、`/api/history?code=600519`、`/api/hourly?code=600519`、`/api/financial?code=600519`。health只证明服务存活。静态发布使用`stock/index.html`、manifest和图标，不依赖Python。源文件和构建产物一并提交到main，由GitHub Pages自动部署；保留向野路书首页。

CSV列：code,name,date,open,high,low,close,volume，日期YYYY-MM-DD，代码保留前导零。至少20条日线；字段内逗号、换行和引号转义暂不支持。仅日线CSV不能代替60分钟数据或复现联合策略。

## 2025年ROE股票池

首页预载2025年年报**加权平均ROE严格大于10%**的沪深北A股，ROE恰好10%不入池；不按ST、行业或板块额外剔除。股票池与一键分析的最新可得财报口径明确区分。用户可按代码、名称、行业搜索，按市场筛选，分页、排序、导出全池CSV或直接点选分析。

初始快照由真实来源全部12页核对生成：2026-10-27北京时间15:11抓取，来源5580条A股2025年年报，1264只达标、4265只ROE≤10%、51只ROE缺失。缺失不当作不达标。来源只覆盖已提供的年报，无法由本表推定未披露／未覆盖公司的数量，也未独立核验当下上市状态。

数据源：RPT_LICO_FN_CPD；固定筛选`REPORTDATE=2025-12-31`和`SECURITY_TYPE_CODE=058001001`，使用WEIGHTAVG_ROE字段，按SECURITY_CODE稳定排序、每页500条，检查总页数、各页长度、总记录数、代码唯一性和统计平衡。分页缺失、总数变化、重复代码、错年或非A股记录时停止替换。公告日缺失明确标记，未来公告不作已披露数据。

`pool-2025.json`为核验快照，构建时校验并内嵌到单文件网页，手机打开即可浏览，不需扫描全市场或依赖云进程。点击“更新来源数据”会重新读取全部分页，完成后一次替换；失败保留原池。页面更新只影响当前页面，发布快照由维护者更新：
