# 知衡 · A 股研究台

六步研究流程：确定约束 → 建立股票池 → 分析企业 → 判断价格 → 交易计划 → 定期复盘。行情及财务通过同源 Python API 获取，研究笔记保存在浏览器。项目独立于原旅行网页。

## 启动

需要 Python 3.9+（含系统时区数据库）、Node.js 18+（测试使用）。无第三方运行依赖，无需 npm install 或 API 密钥。

```sh
cd /workspace/ashare-research
npm start
```

这会启动 `python3 server.py`，默认监听 8010 端口；可用 `python3 server.py --port 8011 --host 127.0.0.1` 覆盖。必须使用此后端，旧的 `python3 -m http.server` 不能提供数据 API。服务需在终端保持运行。本地后端不作为公网入口；手机静态发布版见文末。

## 三项联网功能

### 最新报价与日线筛选

在“建立股票池”输入六位代码。点击“获取最新报价”，或勾选每 30 秒刷新（仅在该页面且浏览器可见时刷新）。每次最多 20 只观察股票，不是全市场扫描。

- 报价源：腾讯财经 `qt.gtimg.cn`，显示交易所北京时间、抓取时间和陈旧状态。不保证无延迟，不是授权逐笔行情；非交易时段的最后报价可能陈旧。
- 日线源：腾讯财经 `web.ifzq.gtimg.cn`，一次最多 8 只，最近至多 640 根，不复权。今天未到北京时间 16:00 的日线不纳入收盘策略，未来日期剔除。自动获取的报价不会替代收盘日线。
- 日线载入成功后替换当前股票池。任何一只失败时保留旧池，并显示错误；不会以演示数据冒充。
- MA20/60 是收盘价简单均值。量比是当日成交量 / 前 20 日均量。ATR14 是最近 14 日真实波幅简单均值，并非 Wilder 平滑。
- 参考股数基于单笔风险预算 / 2×ATR，按 100 股取整且不超账户资金。它不考虑现有组合和实际申报规则，不是订单。

### 自动财务分析

点击股票后，在“分析企业”获取摘要，也可手工输入研究对象代码。

- 数据源：东方财富 `datacenter-web.eastmoney.com` 的 RPT_LICO_FN_CPD 业绩报表，最近 8 期。
- 显示营收、归母利润、EPS、同比、ROE、每股经营现金流，以及报告期和公告日期；没有数据时标为缺失，零值仍为零。
- 分析盈利是否为正、同比变化、累计 ROE，以及经营现金流 / EPS 的粗略匹配。0.8 等阈值是研究规则，不是买卖评分；金融业的现金流不适用一般工业企业解释。
- 全部为年初至期末累计，非单季度或 TTM；不把半年报年化为全年盈利。估值情景仍由用户输入假设，防止机械套用。
- 不自动审计真实性、负债、关联交易、质押和审计意见，需要补读公告。当前摘要可能是修订版，绝不回填历史交易信号。

### 历史回测

先导入 CSV 或获取日线，再到“定期复盘”运行回测。支持普通沪深主板单股票、100 股整手；不支持当前名称包含 ST/退的股票、科创板、创业板或北交所回测。

策略与执行：

1. 收盘价 > 快线 > 慢线时生成入场信号；下一根日线开盘尝试成交。
2. 风险预算决定股数，入场价减 2×入场信号 ATR 为固定风险线；现金不足时减少整手数量。
3. 收盘低于快线或风险线时生成退出信号，下一开盘尝试卖出。因此不是盘中止损，不保证按风险线价格卖出。
4. 不在买入当日卖出；零成交量不成交。开盘涨幅达到默认 4.8% 时不买，开盘跌幅达到 -4.8% 时不卖。这是保守过滤，**不是完整的真实涨跌停模型**；订单当天被过滤后取消，收盘再重新判断。
5. 单边滑点、佣金及最低佣金均可配置。过户费按 2022-04-29 前后 0.002% / 0.001% 分段；卖出印花税按 2023-08-28 前后 0.1% / 0.05% 分段。更早历史费率差异未完整覆盖，不宜用于早期市场。

输出收益、收盘口径最大回撤、已平仓胜率、费用、资金曲线、成交和阻止事件，可导出完整 JSON。没有交易时明确显示，胜率不伪造为零。期末不强制平仓，持仓按收盘估值，未扣未来卖出费。

**回测边界：**不计现金分红、送转、配股、退市、盘口排队、资金容量和历史 ST/新股状态；不复权数据遇除权可能失真，前复权导入也不等同真实现金账户。基准是区间首日收盘到末日收盘的满仓价格变化，不计费用或分红，风险暴露不同于策略。不是全市场历史财务选股回测，没有样本外有效性证明。

## 本地数据、导入与备份

CSV 列：`code,name,date,open,high,low,close,volume`。代码为六位字符串以保留前导零；日期 YYYY-MM-DD，每只至少 61 条。字段内逗号、换行及引号转义暂不支持。数据源、复权和成交量单位须一致，股票身份、交易日和历史状态需自行核查。

内置演示行情是合成数据，始终有演示标识。笔记只保存在当前浏览器 localStorage；清除浏览器数据会丢失，请导出 JSON 备份。行情、财务响应与回测结果只保存在当前页面内存，刷新需重新获取。

## API 与运行要求

- `GET /api/health`：只检查服务存活，不代表上游可用。
- `GET /api/quotes?codes=600519,000001`
- `GET /api/history?code=600519`
- `GET /api/financial?code=600519`

后端只访问固定 HTTPS 域名，保留 TLS 验证，不接收自定义上游地址。报价缓存 10 秒、日线 5 分钟、财务 1 小时；缓存包含原始抓取时间。连接超时或接口变更会显示错误，无模拟回退。公开数据接口不保证稳定性或再分发许可；产品化前需核对供应商授权及服务等级。当前未配置用户认证，适用于隔离研究环境。

## 验证

```sh
npm test
npm run test:api
node --check app.js
node --check integrations.js
```

12 项 Node 测试和 9 项 Python 测试覆盖指标、时点、费用、资金核对、缺失数据、参数校验、缓存与 API 成败。适配器测试使用明确的合成响应，不等于真实数据验证。

2026-10-27 北京时间的独立 Chromium 联调已实测真实报价、日线导入、财务摘要、回测和导出：600519 的 2024-06-04—2026-10-26 区间，580 个回测日，7 笔已平仓、14 笔成交。此案例用于验证流程，不用于推荐股票或证明盈利。摘要见 `validation/live-check.json`。另以模拟响应验证接口故障、演示标签、参数更改后结果失效及手机页面无横向溢出。浏览器验证未发现脚本异常。

## 手机静态发布版

`npm run build` 生成自包含 `dist/index.html`，另附主屏幕 manifest 和图标。此版本不调用 `/api/`，也不依赖临时云机或 Python 服务；手机通过 HTTPS 直接连接腾讯、东方财富公开接口。第三方数据脚本仅在 `sandbox="allow-scripts"` 的隔离 iframe 中运行，没有读取父页面笔记、本地存储或 DOM 的权限。响应经代码、日期和价格校验后再交给原有分析流程。

静态接口适配器另有 4 项测试；总计 16 项 Node 测试、9 项 Python 测试。云环境 Chromium 对平台代理 CA 的默认信任与系统 Python 不同；静态联调通过保留 TLS 验证的系统读取器转发实时上游响应到测试浏览器，不关闭证书校验，不在发布文件中添加代理或放宽 TLS。

发布维护者可用 `npm run build -- /absolute/output/directory` 指定静态输出目录。输出包括 index.html、manifest.webmanifest、icon.svg 和 .nojekyll。笔记只保存在当前域名下的当前浏览器，不会与此前本机开发地址或其他设备自动同步。

发布前静态联调中，真实报价与财务回调通过；历史供应商曾返回 501 限流，因此静态日线/回测连接流程另用明确的测试夹具验证，未将夹具打包到线上。此前真实历史回测证据仍见 validation/live-check.json。供应商限流时可待其恢复或导入可信 CSV，软件不以演示数据冒充真实行情。
