# 缺区观察 · 双色球研究台

发布入口：https://xiaobaibai2046-oss.github.io/xiaobai-first-project/lottery/

沿用仓库现有 GitHub Pages main 分支根目录发布；独立于其他页面。index.html 内嵌脚本、样式和数据，不依赖第三方前端资源。手机 Safari/Chrome 可直接访问，可从浏览器菜单添加到主屏幕（不提供离线缓存）。

规则：所选区的当前遗漏严格超过历史相邻缺席事件平均间隔的2倍时，允许生成另外两区的不同六红。触发不代表下一期缺区已确定。默认采用72组不同六红、每组1蓝，共72注144元；旧全包16蓝保留为可选方案。完整历史六红排除、冷热三连号筛选默认关闭，可主动开启。

## 默认单蓝分散覆盖方案

主目标为：在所选区确实缺席的条件下，至少中一次一等奖或二等奖。默认72组六红互不相同，蓝球分别均匀随机分配一个并展示，允许不同组六红使用同一个蓝球；蓝球在生成时确定，保存时锁定。不会自动购票。每组2元，72组144元。

公平模型下，m组不同六红、每组1蓝的条件概率为：一或二等奖至少一次 m/C(22,6)，一等奖单独 m/[C(22,6)*16]；开奖前不假定缺区时，分别为 m/C(33,6) 与 m/[C(33,6)*16]。72组时条件下一或二等奖约0.0965%（约1036分之一），一等奖约0.00603%（约16581分之一）。这不是预测能力，也不是无条件千分之一。

同样144元，原6+16加两组互不重叠8+1的72注，只覆盖57种不同六红；新方案覆盖72种，因此条件下一或二等奖至少中一次概率相对提高约26.3%，一等奖概率相同。新方案不保证最低小奖，命中一组六红时也不再同时获得15注二等奖。可在页面查看同预算比较，或切换旧全蓝模式。切换方案、组数、筛选会清空尚未保存的当前结果；成本实时重算，不自动维持144元。

默认不强制10/11/12或冷热角色，不排除历史六红；仍限制六红在剩余22个号码内、批次内不重复。额外筛选仅是用户选项，不宣称预测优势。每次生成1—100组，不跨批次去重，实际叠加前应查重。

## 百期历史参考

页面底部提供三区每百期缺席曲线、三区全历史与百期范围汇总表、完整区间统计表。页首快捷入口可直达。按现有历史从第一期开始，每100期顺序、不重叠分组；末尾不足100期单独标记，不连入完整百期曲线，不纳入百期最小/最大值。点选曲线数据点显示具体期号、日期与三地区间比例；表格高亮对应行。手机可在图表或宽表内横向滚动。支持导出当前数据计算的CSV表格和SVG曲线，导入开奖数据后同步重算，不使用过期静态图片。

历史参考独立于推荐条件，仅用于观察。截止内置3523期有35个完整区间及末尾23期。数据仍为未逐期官方核验的第三方快照，缺失/部分历史导入会改变分组结果。

## 缺席间隔参考

页首“缺席间隔统计与分析”直达独立参考区。展示各区缺席次数、完整间隔数量、均值、中位数、95%分位数（排序后向上取值）、最短/最长事件间隔与当前未完成遗漏；按1—5、6—10、11—20、21—30、31—40、41—60、61期以上分组显示数量、比例和图表。提供最长间隔两端的期号/日期，以及全部完整间隔清单（分区筛选、25条分页、两次事件的完整六红）。可导出汇总CSV、完整CSV、SVG分布图。导入开奖后重算。

间隔是相邻缺席事件的开奖索引差，间隔1代表连续两期均缺席；中间连续未发生缺席期数为间隔减1。当前未结束间隔与开头左侧未观察完整部分不计入均值、分布和分位数。无完整间隔时显示未知，不报零均值。

另列“两倍平均”探索性回溯：仅用2014年底前数据确定固定阈值，再分别统计2015—2020、2021年以后开奖前当前遗漏严格超过阈值时的下一期缺席情况；与推荐模块按全历史动态均值触发口径不同。显示分子/分母，训练不足或没有触发时明确标注。这是已查看过数据的回溯，同一段等待中的观察相关，不能当作独立未来验证；不影响推荐条件，不宣称提高一等奖概率。

## 记账与验证

生成组合后填写目标期号、该期官方销售截止时间（北京时间），选择模拟或自报已购，再保存。每期只允许一批；同时锁定同组数、相同蓝球方案和相同成本的随机对照，单蓝时对照蓝球独立随机生成并保存。保存规则参数、数据截至期号与日期、号码、时间和成本。随机对照从01—33均匀抽取六红，无历史号码过滤，不计入实际购买支出。

账本保存在当前浏览器 localStorage，导出JSON可备份或迁移。更换设备、浏览器或清理站点存储不会自动恢复。导入采用合并，完全重复跳过，ID/期号冲突拒绝，不静默覆盖。模拟与自报已购分开，单列待开奖、超时待补数据、数据冲突；已核奖记录才计算回报。

导入完整更新的开奖历史后自动核奖，并保存目标期开奖快照。刷新恢复内置旧开奖时，已保存的核奖快照仍可使用；新导入结果与快照冲突会停止该记录的比较，原值保留。单蓝每组按指定的一个蓝球核1注，全蓝每组展开16蓝核16注；逐注按常规奖级累计固定奖金。分别报告一等奖、二等奖、至少一次一或二等奖的期数及六红全中组数；一、二等奖奖金未知时只报固定奖金下限，不算总收益或ROI。未计派奖、促销、税款或渠道差异，不声称为实际兑奖金额。

保存后无编辑、删除或重抽该期入口，但本地存储、设备时间、输入截止与备份仍可被修改，记录不是独立开奖前存证，不可凭此宣称优势。软件不自动核验官方截止时间与目标期号。所有导入数据需自行核对来源与准确性。

内置3523期第三方快照，截至2026-11-03，非实时数据。支持导入整份JSON/CSV替换，仅当前页面有效，刷新恢复内置快照。请按页面标示的数据末期理解信号。

## 冷热三连号条件

默认关闭，可主动开启附加条件。开启后，6个角色号码互不重复：1个热号＋1个冷号＋3个连续号＋1个随机号。热池为剩余22个号码在最近50期开奖中频次排名前6名，冷池为后6名；同频按号码升序排名，冷池按排名逆序展示，两个池不重叠。连号、随机号本身也可能属于冷热池，因此这里只保证角色数量，不保证整组六红中只有一个号码属于热池/冷池。

默认三连号排除范围为：历史上6红全部落在所选两区的开奖，排除其中所有出现过的三连号。四连号等长连号包含的三连号也计入已出现。界面列出每组被排除三连号的出现期数、首次与最近期号、日期和最近六红。截止内置数据，排除第三区时270期有效历史覆盖19种三连号，唯一剩余为10—11—12。

默认要求恰好一组三连号，不含四连号或额外两连号。可以取消这一限制，或主动改为按全部历史/最近50期排除三连号，或只排完整历史六红。不足时明确提示，不自动放宽。附加条件关闭时，恢复基础缺区随机覆盖。

启用附加条件后，生成时穷举符合角色要求、所选三连号过滤、以及可选历史六红过滤的不同六红并去重，再均匀随机抽取本批。CSV包含角色、范围与开关；保存账本时冻结频次、候选池、可用三连号、角色和条件开关。基础规则、蓝球方案、历史排除开关与不同附加条件分别汇总验证结果，随机对照保持同注数、不加冷热连号过滤。筛选形态没有已验证的中奖概率优势。

新增记录采用版本2，包含蓝球方案、每组策略蓝球、对照蓝球；版本1全蓝记录按原始32元/组与原16注核奖，读取时不改写旧字段。备份容器仍使用版本1，可同时装载两种记录。
