# 缺区观察 · 双色球研究台

发布入口：https://xiaobaibai2046-oss.github.io/xiaobai-first-project/lottery/

沿用仓库现有 GitHub Pages main 分支根目录发布；独立于其他页面。index.html 内嵌脚本、样式和数据，不依赖第三方前端资源。手机 Safari/Chrome 可直接访问，可从浏览器菜单添加到主屏幕（不提供离线缓存）。

规则：所选区的当前遗漏严格超过历史相邻缺席事件平均间隔的2倍，生成另外两区六红，排除历史六红组合，每组覆盖16蓝。规则没有已验证的中奖概率优势。

## 记账与验证

生成组合后填写目标期号、该期官方销售截止时间（北京时间），选择模拟或自报已购，再保存。每期只允许一批；同时锁定同组数、同样包全蓝的随机对照。保存规则参数、数据截至期号与日期、号码、时间和成本。随机对照从01—33均匀抽取六红，无历史号码过滤，不计入实际购买支出。

账本保存在当前浏览器 localStorage，导出JSON可备份或迁移。更换设备、浏览器或清理站点存储不会自动恢复。导入采用合并，完全重复跳过，ID/期号冲突拒绝，不静默覆盖。模拟与自报已购分开，单列待开奖、超时待补数据、数据冲突；已核奖记录才计算回报。

导入完整更新的开奖历史后自动核奖，并保存目标期开奖快照。刷新恢复内置旧开奖时，已保存的核奖快照仍可使用；新导入结果与快照冲突会停止该记录的比较，原值保留。各组六红展开16蓝，逐注按常规奖级累计固定奖金；一、二等奖奖金未知时只报固定奖金下限，不算总收益或ROI。未计派奖、促销、税款或渠道差异，不声称为实际兑奖金额。

保存后无编辑、删除或重抽该期入口，但本地存储、设备时间、输入截止与备份仍可被修改，记录不是独立开奖前存证，不可凭此宣称优势。软件不自动核验官方截止时间与目标期号。所有导入数据需自行核对来源与准确性。

内置3523期第三方快照，截至2026-11-03，非实时数据。支持导入整份JSON/CSV替换，仅当前页面有效，刷新恢复内置快照。请按页面标示的数据末期理解信号。

## 维护

源码与测试在 source/。修改后执行：

```sh
cd lottery/source
npm test
python3 tests/browser_ledger.py http://127.0.0.1:8011/lottery/
python3 build_standalone.py
cp 双色球缺区观察.html ../index.html
```

提交更新后的源码和 lottery/index.html，现有 Pages 设置会发布；不需要额外部署工作流或运行服务器。

浏览器集成测试需先在仓库根目录用 `python3 -m http.server 8011 --bind 127.0.0.1` 启动测试服务器，并安装 Python Playwright、系统 Chromium。此服务器只用于开发验证，不是线上依赖。
