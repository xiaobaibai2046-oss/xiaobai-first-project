# 缺区观察 · 双色球研究台

独立静态网页，无第三方运行依赖，不改动现有旅行网站。需 Python 3；测试需 Node.js 18+。

## 启动

最方便：直接用现代浏览器打开同目录的 `双色球缺区观察.html`，这是包含样式、脚本及3523期开奖的单文件版，不需要安装任何依赖或启动服务器。源码或内置数据修改后运行 `python3 build_standalone.py` 重新生成此文件。

单文件版已通过HTTP浏览器运行测试；当前受管浏览器策略禁止file://导航，因此直接打开本地文件的方式未在此环境验证。若浏览器限制本地文件，请使用下方已验证的服务器方式。

源码开发方式：

```sh
cd /workspace/xiaobai-first-project/lottery/source
npm start
```

服务器使用 8010 端口。通过服务器访问页面，不要直接双击 HTML（模块与数据加载需要 HTTP）。无需 npm install。`npm test` 检查核心计算、触发边界、历史排除与导入校验。

## 规则

- 三区为01—11、12—22、23—33。缺席事件是该区当期一个红球也没出现。
- 平均间隔为所有相邻缺席事件索引差的算术平均，不使用未完成的当前间隔；当前遗漏为最近事件之后完成的开奖数。只有当前遗漏严格超过平均间隔的2倍才能生成。期数不是天数。
- 在另外22个号码中均匀随机抽取不同六红，每批1—100组。默认72组、每组1个随机蓝球、72注144元。历史完整六红排除与冷热三连号条件默认关闭，均可选；旧全16蓝模式保留，每组16注32元。
- 规则是用户设定的筛选方式，没有已证实的概率优势。过去出现的组合仍会再次开出。不同批次不做永久去重；导出后叠加前自行查重，刷新或重新生成不会保留旧结果。
- 公平开奖时每期m组不同六红包全蓝球的一等奖概率为m/1,107,568，与相同数量不重复完整号码的购买方式相同。

## 历史数据

内置3523期，2003-02-23至2026-11-03；不是实时接口。来自 https://github.com/yangxb919/lottery-data 的 data/ssq.json，该仓库标注上游为500.com。尚未与官方逐期核验。内置快照对应原数据SHA256：e4f04549da92c5e8b886fd55f19410da43b3bad05c3895aa860ce62a5f613d4a。

页面列出全部开奖与所选区的全部缺席事件，支持分页、期号/日期/号码检索、缺席区筛选、全部开奖CSV导出、推荐按当前方案展开后的CSV导出（单蓝1行/组，全蓝16行/组）。导出的每行是一注，cost=2元。

可导入替换整份历史数据（不自动合并），仅当前页面有效；刷新后恢复内置数据。请先保存自己的文件。导入成功后会清空旧推荐并重算指标。导入失败保留现有数据。推荐保存与购票均不自动进行。

支持JSON数组或包含draws数组的对象，记录示例：

```json
{"issue":"2026126","date":"2026-11-03","red":[9,10,13,22,29,32],"blue":12}
```

CSV必须为简单逗号分隔数字/日期，无引号字段，表头为：

```csv
issue,date,red1,red2,red3,red4,red5,red6,blue
2026126,2026-11-03,09,10,13,22,29,32,12
```

## 限制

只验证字段、范围、重复期号、日期与期号顺序，并提示年内期号缺口；无法验证数据真实性、缺失的整个年份、年末期数、官方最新期号。缺失记录会影响期数间隔和历史组合过滤。页面数据仅在本地处理，无账号、云同步、自动投注或盈利保证。

新版方案与账本版本兼容说明见上一级 README.md。条件下一或二等奖与一等奖分开显示，旧全蓝账本不会按单蓝重算。
